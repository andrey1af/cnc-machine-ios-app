# Приёмка iOS-приложения

## Подготовка

Понадобятся Xcode с iOS Simulator, локальный `cncbridge` и синтетический файл [preview.gcode](../demo/preview.gcode). Настройте окружение по [инструкции запуска](../README.md#запуск-демонстрации-без-станка). Держите терминал с сервером открытым, чтобы остановить и запустить его для проверки обрыва.

## Основной сценарий

| Действие | Ожидаемый результат |
|---|---|
| Запустить приложение и подключиться к `http://127.0.0.1:8080` | Сервер доступен. Отображается «Контроллер отключён». Вместо XYZ — прочерки |
| На вкладке G-code выбрать `preview.gcode` | Видны имя файла, 9 строк и прямоугольная траектория. «Старт» недоступен, поскольку контроллер отключён |
| Перейти на «Пульт» и обратно в G-code | Предпросмотр той же программы остаётся доступен |
| Открыть «Журнал» с вкладки «Пульт» | Отображается запись о загрузке файла |

## Ошибочный сценарий

| Действие | Ожидаемый результат |
|---|---|
| Остановить локальный сервер через Ctrl+C | Приложение показывает, что сервер недоступен. Кнопка загрузки и настройки шага и скорости заблокированы |
| Не запускать сервер до завершения попыток | Клиент делает до трёх попыток с паузой 5 секунд после каждой ошибки. Затем остаётся статус недоступности |
| Снова запустить сервер и нажать «Подключиться» в меню | После нового статуса загрузка снова доступна. Тестовый файл можно загрузить повторно |

**Успешная проверка** — все результаты из таблиц получены, а основные состояния зафиксированы в [снимках экрана](../demo/screenshots/README.md). Если проверку выполнить не удалось, отмечайте это в [отчёте](../demo/test-summary.md).
