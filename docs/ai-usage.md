# Использование ИИ

Codex помог привести проект к структуре сдачи, вынести правила доступности действий и переподключений в тестируемые модели, написать тесты и подготовить инструкцию демонстрации.

Сведения о сборке, настройках и состоянии API сверяли с исходниками клиента и `cncbridge`. Правила проверяли автоматическими тестами на синтетических данных. Фактический результат и границы проверки указаны в [отчёте](../demo/test-summary.md).

Для тестов и документации не использовались файлы оператора, реальные координаты работы или секреты. Для демонстрации добавлен синтетический G-code. Доступ к локальной сети нужен для связи с `cncbridge`. Разрешения на камеру, микрофон и геолокацию проект не запрашивает.
